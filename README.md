[Laugh Track: The Crypto Trading Joke Contest](https://make.fun/c/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a)
on [make.fun](https://make.fun).

## The joke

> I bought the dip at 3 a.m., then the dip dipped, so now I just stare at the red candle and whisper 'buy the dip' like it's a prayer.

132 characters. Setup: bought the dip at 3 a.m. Turn: the dip dipped.
Punchline: still whispering "buy the dip" like a prayer — the 3 a.m. red-candle
vigil every trader knows.

## How it works

`main.ts` writes the joke as plain text to `/output/entry.txt`. No network, no
secrets, no dependencies — just Node 22.

```sh
node main.ts
cat /output/entry.txt
```
